## Current Status

The **emulator stage is complete for the current scope**.

Linux early boot was reached on 2026-10-08. Linux now boots through OpenSBI
to an interactive BusyBox shell (2026-10-11), with an embedded initramfs.

See the [Emulator Roadmap](emulator/plans/plan.md#emulator-roadmap) for the complete
milestone plan.
